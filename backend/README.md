# HireSense AI FastAPI Backend

Run:

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```

API docs: http://127.0.0.1:8000/docs

Important: replace `backend/data/jobs.csv` with your real `Jobs.csv` from the notebook for real project data.
